# Bedtime-you-little-shit
Byls automatically shuts down your computer at a scheduled time each night, helping you stick to an earlier bedtime.

# Releases
For newer Fedora/Arch based distributions (glibc 2.43+) you can used the precompiled executeable however for older installations/Debian based  distributions you must compile from source using pyinstaller!
